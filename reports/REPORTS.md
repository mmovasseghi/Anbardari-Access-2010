# گزارش‌ها — Access 2010

همه گزارش‌ها از کوئری‌های متناظر ساخته می‌شوند.
مسیر ساخت: Create → Report Wizard یا Report Design

## rptStock — گزارش موجودی

| ویژگی | مقدار |
|---|---|
| نام | `rptStock` |
| Record Source | `qryStock` |
| Caption / Title | گزارش موجودی کالاها |

ستون‌های پیشنهادی:

- کد کالا
- نام کالا
- واحد
- موجودی فعلی
- حداقل موجودی
- وضعیت

## نکات Access 2010

- Orientation: Landscape برای `rptInOut` معمولاً بهتر است
- فونت فارسی خوانا انتخاب کنید (مثلاً Tahoma یا B Nazanin اگر روی سیستم نصب است)
- از قابلیت‌های فقط نسخه‌های جدیدتر Access استفاده نکنید
