# گزارش‌ها — Access 2010

همه گزارش‌ها از کوئری‌های متناظر ساخته می‌شوند.
مسیر ساخت: Create → Report Wizard یا Report Design
استایل مشترک: `docs/UI_DESIGN.md`

## ظاهر مشترک گزارش

| بخش | تنظیم |
|---|---|
| Report Header Back Color | RGB(28, 58, 77) |
| عنوان | Tahoma 16 Bold، سفید، راست‌چین |
| Page Header برچسب‌ها | Tahoma 9 Bold، RGB(28, 58, 77) |
| Detail | Tahoma 9، متن ذغالی |
| خطوط | BorderColor RGB(198, 210, 218) — بدون سایه چندلایه |

## rptStock — گزارش موجودی

| ویژگی | مقدار |
|---|---|
| نام | `rptStock` |
| Record Source | `qryStock` |
| عنوان | گزارش موجودی کالاها |

ستون‌ها: کد کالا، نام کالا، واحد، موجودی فعلی، حداقل موجودی، وضعیت

## rptLowStock — گزارش کالاهای کم‌موجودی

| ویژگی | مقدار |
|---|---|
| نام | `rptLowStock` |
| Record Source | `qryLowStock` |
| عنوان | گزارش کالاهای کم‌موجودی |

ستون‌ها: کد کالا، نام کالا، واحد، موجودی فعلی، حداقل موجودی، کمبود

برای ردیف‌ها می‌توانید ForeColor متن موجودی را RGB(160, 48, 48) بگذارید.

## rptInOut — گزارش ورود و خروج

| ویژگی | مقدار |
|---|---|
| نام | `rptInOut` |
| Record Source | `qryInOut` |
