# آموزش سریع کاربر

## اجرای برنامه

1. پوشه `portable` را باز کنید  
2. روی `شروع.bat` دوبار کلیک کنید  
3. منوی اصلی باز می‌شود  

## کارهای روزمره

### کالای جدید
**مدیریت کالاها** → نام/کد/واحد/حداقل موجودی → ذخیره  
موجودی را دستی عوض نکنید.

### ورود کالا
**ثبت ورود کالا** → اطلاعات سند → ذخیره سند → افزودن اقلام

### خروج / حواله
**ثبت خروج / حواله** → شماره حواله الزامی → ذخیره → افزودن اقلام  
اگر موجودی کم باشد، سیستم اجازه ثبت نمی‌دهد.

### جستجو و موجودی
- **جستجوی کالا**: با چند حرف از نام یا کد  
- **مشاهده موجودی انبار**: لیست کامل + دکمه کم‌موجودی  

### گزارش‌ها
- **گزارش ورود و خروج**: فیلتر و نمایش  
- **گزارش کالاهای کم‌موجودی**: کالاهای رو به اتمام  

## نکته
همیشه از **بازگشت به منوی اصلی** استفاده کنید.
