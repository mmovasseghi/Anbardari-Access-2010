# آموزش سریع

## ۱) نسخه پرتابل (پیشنهادی — همین الان کار می‌کند)

1. فایل ZIP را روی ویندوز باز کنید  
2. بروید داخل پوشه `portable`  
3. روی **`شروع.bat`** دوبار کلیک کنید  
4. منوی فارسی باز می‌شود و کار کنید  

هیچ نصب اضافه‌ای لازم نیست.

---

## ۲) نسخه Microsoft Access 2010 (اختیاری)

اگر Access 2010 دارید:

1. بروید داخل `build`  
2. روی `ساخت-دیتابیس.bat` دوبار کلیک کنید  
3. فایل `database\Inventory.accdb` ساخته می‌شود  

---

## کار روزمره در برنامه

| دکمه | کار |
|---|---|
| ثبت ورود کالا | افزایش موجودی |
| ثبت خروج / حواله | کاهش موجودی (حواله اجباری) |
| مدیریت کالاها | تعریف کالا |
| جستجوی کالا | پیدا کردن سریع |
| مشاهده موجودی انبار | موجودی فعلی |
| گزارش ورود و خروج | با فیلتر |
| گزارش کالاهای کم‌موجودی | کالاهای رو به اتمام |

پیام‌ها فارسی و ساده هستند. موجودی دستی عوض نمی‌شود.
