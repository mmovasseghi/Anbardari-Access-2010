# ظاهر سبک — Access 2010

برای سیستم ضعیف: رنگ و فونت را **یک‌بار در Design View** تنظیم کنید.
VBA تم را هنگام Load اعمال نمی‌کند تا فرم سنگین نشود.

## پیشنهاد

| مورد | مقدار |
|---|---|
| فونت | Tahoma |
| Text Align | Right |
| پس‌زمینه فرم | RGB(236, 241, 245) |
| هدر فرم | RGB(28, 58, 77) + متن سفید |
| دکمه اصلی | RGB(20, 110, 110) + متن سفید |
| دکمه عادی | سفید + حاشیه خاکستری |
