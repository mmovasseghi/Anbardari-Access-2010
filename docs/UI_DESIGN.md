# طراحی رابط کاربری — Access 2010

هدف: ظاهر ساده، خوانا و حرفه‌ای برای سیستم انبارداری، بدون وابستگی به نسخه‌های جدیدتر Access.

## جهت بصری

| نقش | مقدار | RGB |
|---|---|---|
| پس‌زمینه | خاکستری-آبی ملایم | `236, 241, 245` |
| هدر | سرمه‌ای اسلیت | `28, 58, 77` |
| تأکید (Accent) | سبزآبی | `20, 110, 110` |
| متن | ذغالی | `28, 32, 36` |
| خط/حاشیه | خاکستری سرد | `198, 210, 218` |
| هشدار | قرمز ملایم | `160, 48, 48` |
| سطح سفید | سفید | `255, 255, 255` |

فونت اصلی: **Tahoma** (پشتیبانی خوب فارسی در ویندوز + Access 2010)

متن‌ها: راست‌چین (`Text Align = Right`)

## اصول چیدمان

1. **برند اول:** در `frmMain` نام «سیستم انبارداری» بزرگ‌ترین عنصر صفحه است.
2. **یک کار در هر صفحه:** هر فرم فقط یک هدف دارد.
3. **بدون کارت تزئینی:** فقط کنترل‌های لازم.
4. **منوی اصلی خلوت:** برند + یک جمله کوتاه + دکمه‌های اصلی.
5. **اقدام اصلی متمایز:** دکمه ثبت سند / ذخیره با رنگ Accent.

## اعمال تم در Access 2010

ماژول `modUI` رنگ‌ها و استایل دکمه‌ها/برچسب‌ها/تکست‌باکس‌ها را در `Form_Load` اعمال می‌کند.

اگر روی کنترلی خطای نام گرفتید، یا نام کنترل را مطابق مشخصات فرم بسازید یا آن خط `UI_Style...` را موقتاً حذف کنید.

### هدر فرم‌ها

1. Form Header را فعال کنید (View → Form Header/Footer).
2. ارتفاع هدر حدود `1.2cm` تا `1.6cm`.
3. `Back Color` هدر = سرمه‌ای اسلیت.
4. یک Label عنوان سفید و درشت (Tahoma 18–22).

### نوار تأکید (فقط frmMain)

یک Rectangle یا Label به نام `boxAccent` زیر هدر با ارتفاع حدود `0.12cm` و رنگ Accent.

## frmMain — ترکیب پیشنهادی

```
┌─────────────────────────────────────┐
│  سیستم انبارداری                    │  ← هدر سرمه‌ای، برند بزرگ
│  ورود، خروج و کنترل موجودی کالا     │
├─────────────────────────────────────┤  ← نوار Accent نازک
│                                     │
│         [ ثبت سند انبار ]           │  ← دکمه اصلی Accent
│         [ مدیریت کالاها ]           │
│                                     │
│         [ گزارش موجودی ]            │  ← دکمه‌های ثانویه سفید
│         [ گزارش کم‌موجودی ]         │
│         [ گزارش ورود و خروج ]       │
│         [ جستجوی کالا ]             │
│                                     │
│              [ خروج ]               │
└─────────────────────────────────────┘
```

اندازه پیشنهادی فرم: عرض حدود `12cm`، ارتفاع حدود `14cm`  
Default View = Single Form  
Record Selectors / Navigation Buttons / Scroll Bars = No

## فرم‌های عملیاتی

- برچسب‌های فیلد فارسی و راست‌چین
- فاصله یکنواخت بین ردیف‌ها (~0.5–0.6cm)
- Subform اقلام سند با حاشیه ساده و عنوان «اقلام سند»
- برای خروج، برچسب حواله قرمز و با ستاره (`*`)

## گزارش‌ها

- عنوان گزارش در Report Header با همین فونت/رنگ هدر
- خطوط افقی ساده؛ بدون سایه چندلایه
- `rptInOut` ترجیحاً Landscape

## سازگاری

- فقط ویژگی‌های Access 2010
- بدون Web Browser Control اجباری
- بدون تم‌های فقط Access 2013+
- رنگ‌ها با `RGB()` در VBA تنظیم می‌شوند
