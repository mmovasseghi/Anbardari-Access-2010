# نتیجه تست منطق سیستم

محیط Cloud لینوکس است و Microsoft Access 2010 روی آن اجرا نمی‌شود.
بنابراین فایل `.accdb` اینجا باز/اجرا نشد؛ به‌جای آن منطق کسب‌وکار با شبیه‌ساز Python هم‌تراز با VBA تست شد.

## دستور

```bash
python3 tests/test_stock_logic.py
```

## سناریوهای پوشش‌داده‌شده

| سناریو | نتیجه مورد انتظار |
|---|---|
| ورود کالا | افزایش موجودی |
| خروج کالا | کاهش موجودی |
| خروج بیش از موجودی | رد + موجودی بدون تغییر |
| Quantity صفر/منفی | رد |
| خروج بدون حواله | رد |
| چند قلم در یک سند | همه اعمال می‌شوند |
| ویرایش قلم | موجودی اصلاح می‌شود |
| ویرایش خروج نامعتبر | برگشت به حالت قبل |
| حذف قلم ورود | موجودی برمی‌گردد |
| حذف قلم خروج | موجودی برمی‌گردد |
| تشخیص کم‌موجودی | CurrentStock <= MinimumStock |
| نگاشت Combo ورود/خروج | نمایش فارسی / ذخیره IN/OUT |

## باگ رفع‌شده هنگام بازبینی

1. **حذف قلم سند:** قبلاً در `BeforeDelConfirm` موجودی کم/زیاد می‌شد؛ اگر کاربر Delete را Cancel می‌کرد موجودی اشتباه می‌ماند.  
   الان فقط در `AfterDelConfirm` با `Status = acDeleteOK` اعمال می‌شود.

2. **تغییر نوع تراکنش بعد از ثبت اقلام:** قفل شد تا موجودی خراب نشود.

3. **پیام موجودی قابل خروج:** قبل از اعمال OUT، موجودی قابل استفاده نشان داده می‌شود.
