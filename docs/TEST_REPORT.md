# نتیجه تست

Access 2010 روی این محیط نیست؛ منطق با شبیه‌ساز تست شد:

```bash
python3 tests/test_stock_logic.py
```

۱۲ تست OK:

- ورود/خروج موجودی
- جلوگیری از موجودی منفی
- Quantity > 0
- حواله اجباری برای خروج
- چند قلم در سند
- ویرایش/حذف قلم با اصلاح موجودی

رفع باگ مهم: اصلاح موجودی هنگام حذف فقط بعد از تأیید حذف (`AfterDelConfirm`).
