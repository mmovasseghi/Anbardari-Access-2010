# تجربه کاربری اپراتور انبار

مخاطب: مسئول انبار که ممکن است با کامپیوتر حرفه‌ای نباشد.

## قانون طلایی

اگر کاربر برای انجام یک کار روزمره مجبور شود جدول، ID، Query یا اصطلاح انگلیسی ببیند، طراحی اشتباه است.

## منوی اصلی

- دکمه‌های بزرگ، فارسی، عملیاتی
- هر دکمه = یک کار مشخص
- همیشه راه برگشت: **بازگشت به منوی اصلی**

## ثبت اسناد

دو مسیر جدا (نه یک فرم فنی با Combo نوع تراکنش):

1. **ثبت ورود کالا** → نوع داخلی `IN` خودکار
2. **ثبت خروج / حواله** → نوع داخلی `OUT` خودکار + حواله اجباری

در اقلام سند فقط:

- انتخاب کالا از لیست نام‌دار
- تعداد

## موجودی

- کاربر موجودی را دستی عوض نکند
- موجودی فقط با ورود/خروج عوض شود
- پیام کمبود موجودی:

`موجودی این کالا کافی نیست. موجودی فعلی: …`

## جستجو و گزارش

همه فیلترها فارسی و دکمه‌محور:

- جستجو
- نمایش گزارش
- پاک کردن فیلتر
- نمایش فقط کالاهای کم‌موجودی
- بازگشت به منوی اصلی

## Access 2010

نام اشیاء داخلی انگلیسی بماند (`frmMain`, `Products`, …).  
هرچه روی صفحه دیده می‌شود فارسی باشد.
