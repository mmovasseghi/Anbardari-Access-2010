# سیستم ساده انبارداری — Microsoft Access 2010

این برنامه برای **استفاده روزمره در انبار** ساخته می‌شود؛ نه برای برنامه‌نویس و نه برای حسابداری پیچیده.

## هدف اصلی

کاربری که با کامپیوتر خیلی آشنا نیست باید بتواند بدون آموزش طولانی:

1. کالا را پیدا کند  
2. ورود ثبت کند  
3. خروج / حواله ثبت کند  
4. موجودی را ببیند  
5. گزارش بگیرد  

کاربر **نباید** جدول، ID، Query یا اصطلاح انگلیسی ببیند.  
همه کارها از **دکمه‌های فارسی و واضح** انجام می‌شود.

## اصل مهم

**سادگی · واضح بودن · کم بودن مراحل · جلوگیری از اشتباه**

## صفحه اصلی

بعد از باز شدن برنامه، منوی اصلی با دکمه‌های بزرگ:

| دکمه | کار |
|---|---|
| ثبت ورود کالا | سند ورود |
| ثبت خروج / حواله | سند خروج با شماره حواله |
| مدیریت کالاها | تعریف و ویرایش کالا |
| جستجوی کالا | پیدا کردن سریع کالا |
| مشاهده موجودی انبار | لیست موجودی روزمره |
| گزارش ورود و خروج | گزارش با فیلتر ساده |
| گزارش کالاهای کم‌موجودی | کالاهای رو به اتمام |
| خروج از برنامه | بستن برنامه |

## کارهای روزمره

### ثبت ورود کالا
شماره سند، تاریخ، مبدأ، توضیحات + چند قلم کالا (نام کالا + تعداد).  
موجودی خودکار افزایش می‌یابد.

### ثبت خروج / حواله
شماره سند، **شماره حواله**، تاریخ، مقصد، توضیحات + اقلام.  
اگر موجودی کافی نباشد پیام واضح فارسی نشان داده می‌شود و ثبت نمی‌شود.

### مدیریت کالاها
نام، کد، واحد، حداقل موجودی، فعال/غیرفعال.  
**موجودی فعلی دستی تغییر نمی‌کند**؛ فقط از ورود/خروج.

### جستجوی کالا
یک کادر بزرگ: «نام کالا یا کد کالا را وارد کنید»  
حتی با چند حرف پیدا می‌شود. وضعیت: **موجود** / **نیاز به تأمین**

### مشاهده موجودی انبار
لیست همه کالاها + جستجو + دکمه «نمایش فقط کالاهای کم‌موجودی»

### گزارش ورود و خروج
فیلتر ساده: نوع / از تاریخ تا تاریخ / کالا / شماره سند / شماره حواله → دکمه **نمایش گزارش**  
نوع عملیات به فارسی: ورود / خروج

### گزارش گردش یک کالا
از جستجو یا موجودی: ببینید این کالا چقدر وارد/خارج شده و چه اسنادی دارد.

## جلوگیری از اشتباه

- تعداد صفر یا منفی قبول نشود  
- خروج بیش از موجودی ممنوع  
- خروج بدون شماره حواله ممنوع  
- کالا بدون نام ثبت نشود  
- پیام خطا فارسی و ساده باشد (نه Runtime Error)

## نسخه هدف

## سیستم ضعیف

رم حدود ۴ گیگ / CPU قدیمی: فرم‌ها سبک، بدون تم سنگین VBA، فقط امکانات لازم.

## ساخت خودکار روی ویندوز (پیشنهادی)

1. پروژه را روی ویندوز کپی/Extract کنید  
2. وارد پوشه `build` شوید  
3. روی **`ساخت-دیتابیس.bat`** دوبار کلیک کنید  

Access 2010 باز می‌شود و فایل آماده ساخته می‌شود:

`database/Inventory.accdb`

جزئیات: `docs/AUTO_BUILD.md`
