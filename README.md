# سیستم انبارداری — Microsoft Access 2010

پروژهٔ سادهٔ انبارداری سازگار با **Microsoft Access 2010**.

## هدف

- ثبت کالاها
- ثبت اسناد ورود و خروج
- چند قلم کالا در هر سند
- کنترل موجودی (منفی نشود)
- گزارش موجودی، کم‌موجودی، ورود/خروج و جستجوی کالا

## نسخه هدف

| مورد | مقدار |
|---|---|
| پایگاه‌داده | Microsoft Access 2010 |
| قالب پیشنهادی | `.accdb` (ACE 14) |
| زبان رابط کاربری | فارسی |
| نام جداول/فیلدها/فرم‌ها/متغیرها | انگلیسی |

## ساختار Repository

```
sql/          اسکریپت ساخت جداول و روابط
vba/          ماژول‌ها و کد رویداد فرم‌ها
queries/      کوئری‌های گزارش و جستجو
forms/        مشخصات طراحی فرم‌ها
reports/      مشخصات طراحی گزارش‌ها
docs/         راهنمای ساخت و استفاده
```

## شروع سریع روی ویندوز

1. این Repository را دانلود یا Clone کنید.
2. Access 2010 را باز کنید و یک پایگاه‌داده خالی بسازید (مثلاً `Inventory.accdb`).
3. طبق فایل `docs/BUILD_GUIDE.md` جداول، روابط، فرم‌ها، کوئری‌ها و VBA را پیاده کنید.
4. فایل `Inventory.accdb` را در پوشهٔ `database/` همین پروژه نگه دارید (اختیاری ولی توصیه می‌شود).

> چون این محیط لینوکس است و Access 2010 ندارد، فایل باینری `.accdb` اینجا ساخته نمی‌شود.
> تمام سورس‌ها طوری نوشته شده‌اند که روی ویندوز با Access 2010 قابل پیاده‌سازی باشند.

## منطق تراکنش‌ها

| مقدار ذخیره‌شده | نمایش به کاربر | اثر روی موجودی |
|---|---|---|
| `IN` | ورود | افزایش `CurrentStock` |
| `OUT` | خروج | کاهش `CurrentStock` |

قواعد:

- `Quantity` باید بزرگ‌تر از صفر باشد
- برای `OUT` فیلد `DeliveryNumber` الزامی است
- موجودی هیچ‌وقت منفی نمی‌شود
- هر سند می‌تواند چند ردیف در `DocumentItems` داشته باشد

## جداول

- `Products`
- `Documents`
- `DocumentItems`

روابط با Referential Integrity:

- `Documents.ID` → `DocumentItems.DocumentID`
- `Products.ID` → `DocumentItems.ProductID`

## فرم‌ها

- `frmMain` — منوی اصلی
- `frmProducts` — مدیریت کالاها
- `frmDocuments` — ثبت سند
- `frmDocumentItems` — اقلام سند (Subform / Datasheet)

## گزارش‌ها / جستجو

- گزارش موجودی
- گزارش کالاهای کم‌موجودی
- گزارش ورود و خروج
- جستجوی کالا بر اساس نام یا کد

## سازگاری Access 2010

- فقط قابلیت‌های Access 2010
- VBA کلاسیک (بدون ویژگی‌های Office جدید)
- کنترل‌های استاندارد فرم/گزارش
- بدون وابستگی به وب، .NET، یا ابزارهای جدید
