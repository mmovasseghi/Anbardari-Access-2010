# سیستم ساده انبارداری

برای کار روزمره انبار — دکمه‌محور و فارسی.
کاربر نیازی به دانستن جدول، ID یا Query ندارد.

## دانلود و اجرا (پرتابل)

1. پوشه `portable` را روی ویندوز کپی کنید  
2. روی `شروع.bat` دوبار کلیک کنید  

بدون نصب اضافه اجرا می‌شود.

آموزش: [`docs/TUTORIAL.md`](docs/TUTORIAL.md)

## امکانات

- ثبت ورود کالا
- ثبت خروج / حواله
- مدیریت کالاها
- جستجوی کالا
- مشاهده موجودی انبار
- گزارش ورود و خروج با فیلتر
- گزارش کالاهای کم‌موجودی
- گردش یک کالا

## نسخه Access 2010 (اختیاری)

اگر Microsoft Access 2010 دارید:

`build/ساخت-دیتابیس.bat` → می‌سازد `database/Inventory.accdb`

راهنما: `docs/AUTO_BUILD.md`
