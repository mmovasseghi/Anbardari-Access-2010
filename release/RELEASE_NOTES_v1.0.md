# Anbardari Inventory — Release Notes

## v1.0 — نسخه پرتابل ویندوز

فایل آماده استفاده برای همه:

**`Anbardari-v1.0-Windows.zip`**

### نصب / اجرا (۳ قدم)

1. فایل ZIP را دانلود و Extract کنید  
2. وارد پوشه `Anbardari-v1.0-Windows` شوید  
3. روی **`شروع.bat`** دوبار کلیک کنید  

نیازی به نصب Access، Python یا برنامه اضافه نیست.

### داخل بسته

| فایل | کار |
|---|---|
| `شروع.bat` | اجرای برنامه |
| `Start.bat` | همان اجرا (نام انگلیسی) |
| `راهنما.txt` | راهنمای خیلی کوتاه فارسی |
| `app/` | فایل‌های برنامه |
| `data/` | محل ذخیره اطلاعات |

### امکانات نسخه ۱.۰

- ثبت ورود کالا  
- ثبت خروج / حواله با کنترل موجودی  
- مدیریت کالاها  
- جستجوی کالا  
- مشاهده موجودی + کم‌موجودی  
- گزارش ورود و خروج  
- گردش کالا  

### نکته بکاپ

پوشه `data` را گاهی کپی بگیرید تا اطلاعات از دست نرود.
