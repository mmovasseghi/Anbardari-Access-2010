# تجربه کاربرد انباردار (بدون دانش کامپیوتر)

## اصول

- **هیچ ID یا نام جدول** روی صفحه نیست.
- **موجودی** با دست عوض نمی‌شود؛ فقط ورود/خروج نهایی.
- هر فرم دکمه **بازگشت به منوی اصلی** دارد.
- تاریخ را **شمسی** می‌بیند و تایپ می‌کند (مثال `1403/07/01`).

## ثبت ورود (دو مرحله)

1. شماره سند، فاکتور، تاریخ، فروشنده → **ذخیره**
2. اقلام: فقط **نام کالا** (چند حرف تایپ → لیست) + **تعداد**
3. **بررسی و ثبت ورود** → صفحه تأیید با همه اقلام
4. **تأیید و ثبت نهایی** → موجودی زیاد می‌شود

تا قبل از مرحله ۴ موجودی عوض نمی‌شود.

## ثبت خروج (دو مرحله)

مثل ورود؛ هر قلم: **کالا + تعداد + بخش**.

در تأیید نهایی جدول «موجودی فعلی / بعد از خروج» دیده می‌شود.

## سند نهایی

قفل است. برای اصلاح: **باز کردن با کد مدیر** (کد ۶ حرفی از مسئول).

## گزارش‌ها

منوی **جستجو و گزارش‌ها** — نوع گزارش را انتخاب کنید، تاریخ شمسی (اختیاری)، **نمایش گزارش**.

چاپ از Access؛ Excel از منوی خارج کردن گزارش.
