# کد یک‌بارمصرف مدیر (آفلاین)

## هدف

بعد از **ثبت نهایی** سند، انباردار نمی‌تواند سند را عوض کند. برای اصلاح، مدیر یک **کد ۶ کاراکتری** می‌دهد که **فقط یک بار** قابل استفاده است.

## الگوریتم (مشترک با مولد جدا)

ورودی‌ها:

- نوع سند: `INCOMING` یا `OUTGOING`
- `DocumentID`
- `DocumentNumber` (شماره سند همان رکورد)
- نمک سازمان: `UNLOCK_ORG_SALT` در `modConstants` (با برنامه مولد یکسان باشد)

خروجی: ۶ کاراکتر از مجموعه `23456789ABCDEFGHJKLMNPQRSTUVWXYZ`

تابع VBA: `ComputeUnlockCode` در `modUnlock.bas`

## مصرف کد

1. انباردار روی «باز کردن با کد مدیر» می‌زند.
2. `TryUnlockDocument` کد را با مقدار مورد انتظار مقایسه می‌کند.
3. اگر در `UsedUnlockCodes` نباشد → ثبت مصرف + `UnpostDocument` (برگشت موجودی + `IsPosted=False`).

## برنامه مولد (مرحله بعد)

شما گفتید برنامه جدا روی ویندوز آفلاین می‌سازیم. تا آن زمان مدیر می‌تواند در Access Immediate Window تست کند:

```vba
? ComputeUnlockCode("INCOMING", 1, "سند-001")
```

**توجه:** اگر الگوی خاص دیگری مدنظر دارید (مثلاً تاریخ انقضا در کد)، بگویید تا `modUnlock` و مستند را هماهنگ کنیم.
