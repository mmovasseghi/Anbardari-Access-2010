# ظاهر سبک برای اپراتور

- فونت: Tahoma  
- متن‌ها راست‌چین و فارسی  
- دکمه‌های منوی اصلی بزرگ و خوانا  
- بدون شلوغی و بدون اصطلاح انگلیسی روی صفحه  
- رنگ‌ها را یک‌بار در Design تنظیم کنید (نه VBA سنگین)

پیشنهاد رنگ:

- هدر: RGB(28, 58, 77) متن سفید  
- دکمه اصلی: RGB(20, 110, 110) متن سفید  
- پس‌زمینه: RGB(236, 241, 245)
