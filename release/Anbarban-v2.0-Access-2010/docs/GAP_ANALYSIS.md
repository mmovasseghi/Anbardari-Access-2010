# تحلیل شکاف — پروژه قبلی در برابر مشخصات انباربان

## وضعیت قبلی (قبل از این بازطراحی)

| موضوع | وضعیت قبلی | مشخصات شما |
|---|---|---|
| جداول | ۳ جدول: `Products`, `Documents`, `DocumentItems` | ۷ جدول + فروشنده و بخش |
| ورود/خروج | یک جدول سند با `TransactionType` | اسناد ورود و خروج جدا |
| فروشنده | فیلد متنی `Source` | جدول `Suppliers` |
| مقصد خروج | یک `Destination` برای کل سند | `DepartmentID` روی **هر قلم** |
| فاکتور خرید | نداشت | `InvoiceNumber` روی سند ورود |
| موجودی | با ذخیره هر قلم بلافاصله عوض می‌شد | فقط بعد از **تأیید نهایی** |
| تأیید دو مرحله‌ای | نداشت | بررسی → گزارش تأیید → ثبت نهایی |
| منوی اصلی | ۸ دکمه (بدون فروشنده/بخش) | ۹ دکمه طبق سند شما |
| گزارش‌ها | ورود/خروج + کم‌موجودی | مجموعه گزارش‌ها + فیلتر ترکیبی |
| تاریخ | میلادی | **شمسی** (ورود و نمایش) |
| سند نهایی | قابل ویرایش | **قفل** + باز کردن با **کد ۶ رقمی یک‌بارمصرف** (مولد جدا بعداً) |

## تصمیم‌های پیاده‌سازی (هماهنگ با پاسخ شما)

1. **دیتابیس خالی** — جداول `Documents` / `DocumentItems` حذف و جایگزین کامل؛ بدون مهاجرت داده.
2. **تاریخ** — در جدول به‌صورت `Date/Time` (میلادی) برای مرتب‌سازی و گزارش بازه؛ روی فرم **ورود و نمایش شمسی** (`modJalali`).
3. **سند نهایی** — `IsPosted = True` → فرم فقط‌خواندنی؛ ویرایش فقط با کد معتبر (`modUnlock` + جدول `UsedUnlockCodes`).
4. **سخت‌افزار** — کوئری‌های ساده، بدون سرویس خارجی؛ مناسب Pentium و ۴GB RAM و Access 2010.

## فایل‌های کلیدی بعد از بازطراحی

- `docs/SCHEMA.md` — شمای ۷ جدول
- `vba/modPost.bas` — ثبت نهایی و موجودی
- `vba/modJalali.bas` — تاریخ شمسی
- `vba/modUnlock.bas` — کد مدیر (رابط مولد آفلاین)
- `vba/frmIncoming*` / `frmOutgoing*` — ثبت دو مرحله‌ای
- `vba/frmReports_Code.bas` — جستجو و گزارش‌ها
