# انباربان — نسخه ۲.۰ (Access 2010)

## برای چه کسی است؟

انبار سازمانی روی **ویندوز + Microsoft Access 2010** (مثلاً Pentium، ۴GB RAM).  
انباردار بدون تجربه کامپیوتر: فقط دکمه و تاریخ شمسی.

## دانلود

فایل **`Anbarban-v2.0-Access-2010.zip`**

## نصب و اولین اجرا (۴ قدم)

1. ZIP را Extract کنید (مثلاً `C:\Anbarban`)
2. **Access 2010** باید نصب باشد
3. روی **`شروع-ساخت-دیتابیس.bat`** دوبار کلیک کنید  
   → فایل `database\Inventory.accdb` ساخته می‌شود و Access باز می‌ماند
4. از منوی **انباربان** کار کنید

اگر قبلاً `Inventory.accdb` دارید، اسکریپت یک نسخه پشتیبان می‌گیرد و دیتابیس جدید می‌سازد.

## امکانات نسخه ۲.۰

| قابلیت | توضیح |
|--------|--------|
| ۷ جدول | کالا، فروشنده، بخش، ورود/خروج جدا |
| ثبت ورود دو مرحله‌ای | پیش‌نویس → تأیید با فاکتور → موجودی |
| ثبت خروج دو مرحله‌ای | هر قلم **بخش** جدا + کنترل موجودی |
| تاریخ شمسی | ورود روی فرم (مثال `1404/01/15`) |
| جستجوی نام کالا | چند حرف تایپ → انتخاب از لیست |
| گزارش‌ها | ورود، خروج، فروشنده، بخش، حواله، گردش کالا، موجودی |
| سند نهایی قفل | باز کردن با **کد ۶ رقمی** مدیر |

## کد مدیر (آفلاین)

در پوشه `tools`:

```text
python generate_unlock_code.py INCOMING 1 "شماره-سند"
```

یا بعداً برنامه مولد جدا — الگوریتم در `docs/MANAGER_UNLOCK.md`
