# این پوشه برای فایل نهایی Access است

پس از ساخت دیتابیس روی ویندوز با Access 2010، فایل را اینجا قرار دهید:

```
database/Inventory.accdb
```

این محیط Cloud فایل `.accdb` باینری تولید نمی‌کند، چون Microsoft Access روی لینوکس نصب نیست.
ساخت واقعی باید روی سیستم Windows + Access 2010 انجام شود (راهنما: `docs/BUILD_GUIDE.md`).
