# نسخه پرتابل (بدون نصب)

این پوشه را روی ویندوز کپی کنید و اجرا کنید.

## اجرا

روی یکی از این‌ها دوبارکلیک کنید:

- `شروع.bat`
- یا `Start.bat`

برنامه بدون نصب Python / Access باز می‌شود (با `mshta` ویندوز).

## امکانات

- ثبت ورود کالا
- ثبت خروج / حواله
- مدیریت کالاها
- جستجوی کالا
- مشاهده موجودی
- گزارش ورود و خروج
- گزارش کم‌موجودی
- گردش یک کالا

داده‌ها اینجا ذخیره می‌شوند:

`portable/data/inventory.json`

## نکته

نسخه Access 2010 جداگانه در ریشه پروژه است (`build/ساخت-دیتابیس.bat`).
نسخه پرتابل همین الان قابل استفاده روزمره است.
